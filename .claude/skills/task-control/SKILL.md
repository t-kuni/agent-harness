# タスク制御機構

タスクキュー（TASK.md）とタスクエージェント（scripts/task-agent.sh）の総称。

## タスクキュー（TASK.md）

処理待ちのタスクを管理するファイル。上から順に処理され、完了したタスクは削除される。

### 書式

```
* [ ] タスク1の説明
    * タスク1の補足
* [ ] タスク2の説明
    * タスク2の補足
```

## タスクエージェント（scripts/task-agent.sh）

タスクキューを監視し、タスクを1件ずつ自動処理するスクリプト。

* 起動はオーナーが `scripts/task-agent.sh` を直接実行する
* AIエージェントは自律的に起動・操作しない

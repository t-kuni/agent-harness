# タスクエージェント

`scripts/task-agent.sh` をフォアグラウンドで起動し、タスクキュー（TASK.md）のタスクを1件ずつ自動処理する。

## 実行手順

1. 以下のコマンドをフォアグラウンドで実行する：

```bash
bash scripts/task-agent.sh [待機秒数]
```

## オプション

- 待機秒数（デフォルト: 60）: タスクキューが空の場合に待機してから終了するまでの秒数

## 停止方法

実行中のターミナルで `Ctrl+C` を押す。

## 動作仕様

- タスクキューが空(0byte)の場合: 指定秒数待機してループ終了
- タスクがある場合: `claude -p --verbose --output-format stream-json` を起動して先頭の1タスクを処理し、タスクキューを更新する
  - ツール呼び出しが `[TOOL] ツール名 入力パラメータ` 形式でリアルタイムに標準出力へ表示される
  - `--output-format stream-json` には `--verbose` が必須（片方だけではエラー）
- タスク完了後は再度タスクキューをチェックして次のタスクへ進む
- 全タスク完了後はタスクキューが空になりループが終了する
- `claude -p` がエラーで失敗した場合: `notify-send` で通知してエラー終了する

## タスクキュー（TASK.md）の書式

```markdown
* [ ] タスク内容
    * 補足説明
    * 参照ハーネス: path/to/harness.md
```

- 新タスクは依存関係を考慮して任意の位置に挿入してよい
- `参照ハーネス:` を書くと処理時に必ずそのファイルを参照する

# 特殊ハーネスについて

## `CLAUDE.md`

* 常に必要な知識を配置する
* ここに追記することは基本的に無い想定

## `.claude/skills/`

* 必要に応じて参照させたい知識を配置する
* frontmatter の description を索引とし、AIエージェントが自動的に知識を参照する
  * descriptionには知識のwhat(何か？), when(いつ参照するか？)を記述する


# ハーネスに知識を追加・変更する手順

1. ハーネスに「追加したい知識」を明確にする
2. SSoTチェック
  * 「追加したい知識」がすでにハーネスに記述されていないか確認する
  * 複数キーワードを grep するなどして探す
3. 配置先チェック
  * 「追加したい知識」が書かれているべきハーネスを検討する
  * ハーネスの種類・役割を考慮する（ハーネスの種類は `CLAUDE.md` を参照）
  * その知識を「どのタイミングで知っておく必要があるか」に基づいて判断する
  * メタハーネスは必ず特殊ハーネスとする
    * メタハーネス × 自然ハーネスの組み合わせは禁止
4. 判定
  * SSoTチェックNG ✕ 配置先チェックNG
    * すでに知識が存在するが、適切な箇所に記載されていない
    * 対処方法：知識の記述箇所を移動する or 最適な箇所にリンクを追加する
  * SSoTチェックNG ✕ 配置先チェックOK
    * すでに知識が存在し、適切な箇所に記載されている
    * 対処方法：なにもしなくていい or 別の対処方法が必要（「追加したい知識」で問題が解決しない可能性を疑う）
  * SSoTチェックOK
    * 対処方法： 適切なハーネスに追記or新規作成
5. ハーネスを追加・変更する

# 執筆ルール

* 日本語で書く
* SSoT（Single Source of Truth、１事実１箇所） を厳守する
* ドメイン固有の知識を書く
  * LLMがすでに知っている知識は書かない（一般論など）
* 「完了条件の検証」や「成果物の品質の確認」は決定論的に検証できないかを検討する
* 同一レイヤーに既存ファイルがある場合、1つ参照して書式を合わせる
* 最新情報のみを保持する（古くなった情報は削除する）

---
name: bootstrap-domain-harness
description: 現在のタスクに必要なドメインハーネスを最小構成で作成または更新する
---

目的:
現在のタスクに必要なドメインハーネスを、タスクに最適な構造で作る。

原則:
- フォルダ構造・ファイルフォーマット・配置先は固定しない。タスクの性質に合わせて都度設計する。
- 既存のドメインハーネスへ統合できるなら新設しない。

手順:
1. オーナー要求からドメイン名、完了条件、制約、入力、出力を抽出する。
2. 既存のドメインハーネス候補を調べ、流用できるものがあれば再利用する。
3. 足りなければ、タスクに最適な場所・構造でドメインハーネスを新設する。
   - 知識の種類（仕様、手順、検証、参照先など）に応じてファイルを分割するか統合するかを判断する。
   - 機械可読な SSoT（仕様書、スキーマ、サンプル出力など）は適切な場所へ置く。
4. 完了条件ごとの確認方法・実行入口・期待結果・手動確認点を記載する。
5. 決定論的検証を作れるなら、その入口を既存プロジェクト方式で追加し、検証情報へ反映する。
6. メタハーネスへ統合すべき学びがあれば更新する。

出力要件:
- 追加・更新したファイルを列挙する。
- どの完了条件をどの検証へ対応付けたか示す。
- まだ決定論化できていない点を明示する。

## 手順

### 1. 文章の長さ目標を取得する

案の数を `-n` に指定してスクリプトを実行する。

```bash
python3 .claude/skills/idea-antibias-technic/text_len.py -n <案の数>
```

出力例: `文章の長さ I1:2(40) I2:4(60) I3:2(30) I4:3(51)`

* 書式: `I<番号>:<文数>(<合計文字数>)`
* 外部パッケージ不要のため `.venv` なしで実行可能

### 2. 各案を執筆する

各案を書く前に手順1の出力を参照し、その案に割り当てられた文数・合計文字数に合わせて執筆する。

執筆時の制約:

* `CLAUDE.md` の「AI臭さを避けるルール」に従う
* 文末パターン（〜て・〜た・〜る・〜ない等）を案内・案間でバラけさせる
* 句節文の長さを文ごとにバラけさせる

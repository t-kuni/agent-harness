## ルール

- `codex exec` は `Bash` ツールで直接実行する（同期実行）。`TaskCreate` による非同期実行は禁止
- 画像の読み込み・説明はcodexのみが担当する（セキュリティのため最小権限）
- claude code は画像ファイルを直接読み込まない（コンテキストウィンドウ節約）
- 対象画像はリポジトリ内に存在する前提（絶対パスで指定）

## 手順

1. 対象画像の絶対パスを確認する

2. codex を実行して画像の内容を標準出力に取得する（`<IMAGE_PATH>` を実際の絶対パスに置き換える）

```bash
echo "この画像の内容を詳細に説明してください。テキスト、図形、色、レイアウト、UI要素など視覚的な情報をすべて日本語で出力してください。" | codex exec \
  --model gpt-5.5 \
  --sandbox read-only \
  --ephemeral \
  --skip-git-repo-check \
  --config 'approval_policy="never"' \
  -i <IMAGE_PATH>
```

3. 標準出力の内容を画像の説明として把握し、オーナーへの回答やその後の作業に使用する

## エラー時の対応

codex コマンドが失敗した場合（認証エラー・コマンド不在・その他）、代替手段で自己解決しない。
オーナーにエラー内容を報告し、指示を仰ぐ。

## 出力

- 画像の内容説明（codexの出力をそのまま使用）

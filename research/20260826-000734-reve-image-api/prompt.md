# このリポジトリについて

このリポジトリは「ハーネス」と呼ばれる、AIエージェント（Claude Code）が参照する知識ファイル群を管理している。
既存の知識として `.claude/skills/image-gen/SKILL.md` があり、画像生成を行うスキルを定義している。
このスキルは現状、以下の3方式で画像生成APIを直接呼び出す実装を持つ。

- OpenAI `gpt-image-2` API直接呼び出し（デフォルト方式）。エンドポイントは `/v1/images/generations`（新規生成）と `/v1/images/edits`（参照画像を使った編集・合成）の2種類に分かれている。認証はAPIキーによるBearer認証。パラメータとして `size`（`WIDTHxHEIGHT`形式、任意の解像度を16の倍数などの制約付きで指定可能）がある。
- codex CLI経由の画像生成（サブ手段）
- Google Gemini API（`gemini-3.1-flash-image`、通称nano banana2）の `POST /v1beta/interactions` エンドポイント直接呼び出し（サブ手段）。エンドポイントは参照画像の有無によらず単一。解像度は `ASPECT_RATIO`（比率）と`IMAGE_SIZE`（サイズクラス：512/1K/2K/4K）の組み合わせで指定する方式。参照画像は複数枚（最大10枚程度）渡せる。

このリポジトリでは、新しい画像生成API（Reve社の「Reve 2.1」モデル）を上記スキルに新しい方式として追加することを検討しており、そのためにReve 2.1の公開API仕様を正確に把握する必要がある。

# 問い

Reve社（reve.com）が提供する画像生成モデル「Reve 2.1」について、開発者向けAPI（`https://api.reve.com` 配下、コンソールURL: `https://api.reve.com/console`）の以下の仕様を、公式ドキュメントに基づいて明らかにせよ。

1. APIのベースURL・具体的なエンドポイントパス一覧（新規画像生成用、既存画像の編集・リミックス用、その他関連エンドポイールがあれば全て）
2. 各エンドポイントのHTTPメソッド、認証方式（APIキーの取得方法・ヘッダー名・形式）
3. 各エンドポイントのリクエストボディのパラメータ一覧（パラメータ名・型・必須/任意・デフォルト値・取りうる値の範囲や選択肢）。特に以下の点を明確にすること。
   - プロンプトの指定方法（テキストプロンプトのパラメータ名、ネガティブプロンプトの有無）
   - 画像サイズ・解像度・アスペクト比の指定方法（パラメータ名、固定解像度指定が可能か、比率＋サイズクラスの組み合わせ方式か、それぞれの取りうる値）
   - 参照画像（画像編集・画像合成・スタイル一貫性維持用の入力画像）の渡し方（パラメータ名、Base64埋め込みかURLかmultipartか、渡せる枚数の上限）
   - 生成枚数・シード値・その他生成パラメータ（あれば）
4. 各エンドポイントのレスポンスボディの構造（画像データの返却形式：Base64かURLか、その他メタデータ）
5. レート制限の仕様（あれば：リクエスト数上限、時間窓、ヘッダーでの通知方法）
6. 料金体系（あれば：課金単位、価格、無料枠の有無）
7. エラーレスポンスの形式・代表的なエラーコード

# 出力要件

- 日本語で記述すること
- 前提知識を持たない読者でも理解できる粒度で記述すること
- 各項目について、公式ドキュメント（`https://api.reve.com` 配下のページ、`https://docs.reve.com` 等の公式サイト）に基づいた事実のみを記述し、情報源のURLを明記すること
- 該当するAPI呼び出し例（curlコマンド等）が公式ドキュメントに掲載されている場合は、そのまま引用すること
- 公式ドキュメントで確認できなかった項目は「不明」「公式ドキュメントに記載なし」と明記し、推測で埋めないこと
- 出力の構成は上記の問いの1〜7の項目に対応する見出しを立てて整理すること

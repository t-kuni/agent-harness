# 問い

動画生成AIサービスにはどのようなものがあり、それぞれどのような入力パラメータ（プロンプト、開始フレーム画像、終了フレーム画像、セリフ・音声指定）と、API・MCPサポートを備えているか。

# 背景

動画生成サービスを比較検討し、利用候補を絞り込みたい。
特に、テキストプロンプトに加えて「最初のフレーム画像」「最後のフレーム画像」「音声（セリフ）」を個別に指定して動画を生成できるサービスを重視している。
また、プログラムから呼び出せるAPI、あるいはMCP（Model Context Protocol）サーバーとしての提供があると望ましい。

# 出力要件

以下の情報を含む、動画生成サービスの一覧表（Markdown形式）を作成すること。

- サービス名・提供元
- 公式サイトURL
- テキストプロンプトによる動画生成の可否
- 開始フレーム画像（先頭フレーム）指定の可否
- 終了フレーム画像（最終フレーム）指定の可否
- セリフ・音声（音声トラックやセリフの指定）生成・指定の可否
- API提供の有無（提供している場合はドキュメントURL）
- MCPサーバー提供の有無（公式・非公式問わず、存在する場合は情報源URL）
- 料金体系の概要（分かる範囲で）

一覧表の後に、各サービスについて機能の詳細や制約事項（例：フレーム指定が一部プランのみ対応、解像度や尺の上限など）を補足として記述すること。

情報源は可能な限り各サービスの公式ドキュメント・公式サイトを優先し、参照したURLを明記すること。

出力言語は日本語とすること。

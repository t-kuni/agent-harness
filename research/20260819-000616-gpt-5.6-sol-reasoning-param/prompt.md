# このリポジトリについて

これは Claude Code（Anthropic製CLIエージェント）向けの「ハーネス」を管理するリポジトリである。ハーネスとは、AIエージェントが参照する知識ファイル群の総称で、`.claude/skills/<スキル名>/SKILL.md` の形式でスキルが定義される。このリポジトリには汎用的なWebリサーチを行う `research` スキルがある。

過去のリサーチにより、OpenAIのDeep Research用モデルであった `o3-deep-research` `o4-mini-deep-research` は2026年7月23日にシャットダウンされ、推奨移行先として `gpt-5.6-sol` が案内されていることが判明した。`gpt-5.6-sol` はResponses API (`POST https://api.openai.com/v1/responses`) 経由で利用でき、`web_search` 等のホスト型ツールを使う限りは1回のAPIリクエスト内でサーバー側が自動的に複数回ツール呼び出しを継続する（エージェント的ループが成立する）ことも判明している。この `gpt-5.6-sol` を用いて `research` スキルの自律調査を実現する方法を検討する過程で、推論量（reasoning effort）を制御できるかどうかが不明なため本リサーチを行う。

# 問い

OpenAIのResponses APIにおいて、`gpt-5.6-sol` モデルの推論量（reasoning effort、思考の深さ）を制御するパラメータが公式に提供されているか。以下を明らかにせよ。

1. `gpt-5.6-sol` のモデルページ（`developers.openai.com/api/docs/models/gpt-5.6-sol` 等）に、推論量を制御するパラメータ（例：`reasoning.effort`）に関する記載があるか。ある場合、パラメータ名・指定可能な値（例：`minimal`/`low`/`medium`/`high` 等の列挙値）・デフォルト値を明記する。
2. Responses APIの公式リファレンス（`developers.openai.com/api/docs/api-reference/responses` 等）における `reasoning` パラメータの仕様（型、サブフィールド、各サブフィールドの意味・指定可能な値）を明らかにする。
3. 推論量（`effort`）の値によって、料金（入力/出力トークン単価）が変化するのか、それとも単価は固定でトークン消費量（＝実質コスト）のみが変化するのかを明らかにする。
4. 推論量の指定が、レイテンシ・応答の質にどう影響するかについて公式ドキュメントに記載があれば明記する。
5. `gpt-5.6-sol` 固有の推奨設定（Deep Research的な多段階自律調査に用いる際の推奨 `effort` 値など）が公式ドキュメントに記載されていないか確認する。
6. 公式情報で確認できない項目があれば、その旨と、確認のために参照したURL・検索クエリの結果概要を明記する。

# 出力要件

- 日本語で記述すること。
- 公式ドキュメント・公式ブログ・公式Changelogを最優先で参照し、URLを明記すること。二次情報サイトを使う場合はその旨を明記し、公式情報と区別すること。
- 「できる」「できない」を推測ではなく、実際に参照できたソースに基づいて明言すること。断定できない場合は「確認できなかった」と明記すること。
- サンプルのAPIリクエスト（curl等の疑似コード可）が公式ドキュメントに存在する場合は、そのまま引用すること。
- 参照した公式ドキュメント・情報源のURLをすべて出力の末尾に列挙すること。
- 選択肢の提示や好み・推奨の表明は不要。事実の確認結果のみを記述すること。

# 問い

以下の4種類の入力を、1回のAPI呼び出し（または1回の生成リクエスト）に同時に渡すことで、1本の動画を生成できる動画生成AIサービスは存在するか。存在する場合、それはどのサービスのどの機能・エンドポイントか。

- テキストプロンプト
- 開始フレームの画像（動画の最初のフレームとして使われる画像）
- 終了フレームの画像（動画の最後のフレームとして使われる画像）
- セリフの音声データ（この音声データの発話内容に合わせて、動画中の人物・キャラクターの口の動きがリップシンクされること）

すなわち、開始フレーム画像と終了フレーム画像による動画の始点・終点の制御（first-last-frame / keyframe interpolation）と、外部から与えた音声データに対するリップシンク生成を、同一の生成リクエスト内で両立できるサービス・機能を特定したい。

# 背景

動画生成サービスを比較検討し、利用候補を絞り込みたい。
「開始フレーム・終了フレームの指定」と「外部音声データへのリップシンク」は、多くのサービスでは別々の機能（例：keyframe補間の機能と、アバター/トーキングヘッド用のリップシンク機能）として提供されており、両方を1回の生成リクエストで同時に指定できるとは限らない。
この2つの機能が同一リクエスト内で両立可能かどうかを、サービスごとに明確に切り分けて確認したい。

# 出力要件

以下を含む調査結果をMarkdown形式で作成すること。

1. 「開始フレーム画像」「終了フレーム画像」「外部音声データによるリップシンク」「テキストプロンプト」の4つを同一の生成リクエストに同時入力できるサービス・エンドポイントが存在するかどうかの結論を、確認できた範囲で明記する。
2. 該当する可能性があるサービスごとに、以下を記載する。
   - サービス名・提供元
   - 該当する機能・APIエンドポイント名と公式ドキュメントURL
   - 開始フレーム画像パラメータの名称と仕様
   - 終了フレーム画像パラメータの名称と仕様
   - 音声データ入力パラメータの名称と仕様（音声ファイルの形式、リップシンクの挙動の説明）
   - 上記4要素を同一リクエストで同時に指定可能かどうかの根拠（ドキュメントの記述を引用またはURL付きで明記）
   - API・MCPサーバーの提供有無
3. 4要素すべてを同時に満たすサービスが見つからない場合、どの組み合わせが不足しているか（例：開始/終了フレームは対応するが音声リップシンクは非対応、など）をサービスごとに整理する。
4. 情報源は各サービスの公式ドキュメント・公式サイトを優先し、参照したURLをすべて明記する。

出力言語は日本語とすること。

# このリポジトリについて

このリポジトリは「agent-harness」と呼ばれる、AIエージェント（Claude Code）が参照する知識ファイル群を管理するプロジェクトである。今回のリサーチはこのリポジトリの技術選定・ツール調査の一環として行う。リポジトリ自体の構造は本リサーチの問いには直接関係しない。

# 問い

xAI社が提供するAIモデル「Grok」について、以下を明らかにせよ。

1. Grokは次のどの利用方式で提供されているか（該当するものすべて）。それぞれの提供有無と概要を明らかにすること。
   - API（開発者向けAPIエンドポイント。例：REST API、OpenAI互換API等）
   - MCP（Model Context Protocol サーバーとしての提供、または公式MCPサーバーの有無）
   - CLI（コマンドラインインターフェースツールとしての提供。公式・非公式問わず、xAI公式が提供するものがあるか）
2. Grokの料金体系はどうなっているか。
   - サブスクリプション型のプラン（個人向け・法人向けを含む）の種類、月額/年額料金、含まれる内容
   - API利用時の従量課金（トークン単価等）の料金表。モデルバリエーション（例：Grok 4、Grok 4 Fast等）ごとの料金の違い
   - 無料枠の有無

# 出力要件

- 日本語で出力すること
- 前提知識のない読者にも理解できるように、専門用語には簡潔な説明を添えること
- 公式情報源（xAI公式サイト、xAI公式ドキュメント）を最優先で参照し、情報源のURLを明記すること
- 情報の取得日時点でのバージョン・提供状況であることを明記すること
- 出力は以下の構成とすること
  1. 概要（3〜5行で全体像をまとめる）
  2. 利用方式（API / MCP / CLI）の一覧表または箇条書き
  3. 料金体系の詳細（サブスクリプション・従量課金それぞれ）
  4. 参照した情報源のURL一覧

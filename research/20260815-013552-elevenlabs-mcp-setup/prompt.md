# このリポジトリについて

このリポジトリは「agent-harness」と呼ばれる、AIエージェント（Claude Code）が参照する知識ファイル群を管理するリポジトリである。
Claude Code は Anthropic 製の CLI ツールで、MCP（Model Context Protocol）サーバーを設定に追加することで、外部ツール・サービスをエージェントから呼び出せるようになる。
MCP サーバーの設定は Claude Code の設定ファイル（`.mcp.json` や `claude mcp add` コマンドなど）を通じて行う。

# 問い

ElevenLabs が公式に提供している MCP サーバーを、Claude Code（またはその他の主要な MCP 対応クライアント）に導入する手順を明らかにせよ。

# 出力要件

- ElevenLabs MCP サーバーの正式名称・提供元（公式パッケージ名、GitHub リポジトリ URL、npm/pip などの配布形態）
- 導入の前提条件（必要なAPIキーの取得方法、アカウント種別、料金プランの制約など）
- インストール手順（コマンド例を含む、具体的な手順を番号付きで）
- Claude Code から利用する場合の設定方法（設定ファイルの記述例、`claude mcp add` コマンドなど、複数の導入方法がある場合はそれぞれ記載）
- 利用可能な主なツール・機能の一覧（音声合成、音声認識、音声クローンなど、MCPサーバーが提供する機能）
- 既知の制約・注意点（認証エラー、レート制限、対応バージョンなど）
- 参照した公式ドキュメントのURL一覧

出力は日本語で、上記の項目ごとに見出しを分けたMarkdown形式で記述すること。
前提知識を持たない読者でも手順どおりに実行できる粒度で記述すること。

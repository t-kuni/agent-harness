# このリポジトリについて

これは Claude Code（Anthropic製CLIエージェント）向けの「ハーネス」を管理するリポジトリである。ハーネスとは、AIエージェントが参照する知識ファイル群の総称で、`.claude/skills/<スキル名>/SKILL.md` の形式でスキルが定義される。このリポジトリには汎用的なWebリサーチを行う `research` スキルがあり、現在はサブエージェント（Claude自身によるWebSearch/WebFetch）またはOpenAIのCodex CLIをサブプロセス実行する方式でリサーチを行っている。今後、OpenAIが提供する「Deep Research」というAPI（存在する場合）を `research` スキルの実行方式の一つとして直接HTTPリクエストで呼び出せるようにすることを検討しており、その判断材料として本リサーチを行う。

# 問い

OpenAIは2026年8月時点で「Deep Research」を実行できるAPIを提供しているか。以下を明らかにせよ。

1. OpenAIの公式ドキュメント（platform.openai.com、openai.com/index、openai.com/api 等）・公式ブログ・公式Changelogにおいて、「Deep Research」と呼ばれる機能・モデル・APIが存在するか。存在する場合、それが具体的にどのAPI（Responses API のツール機能なのか、専用エンドポイントなのか、Agents SDK上の機能なのか等）として提供されているかを明記する。
2. 存在する場合、使用するモデルID（例：`o3-deep-research`、`o4-mini-deep-research` 等、実際に公式ドキュメントに記載されている名称）と、そのモデル・機能のAPIエンドポイントURL、リクエストの形式（HTTPメソッド・エンドポイントパス・リクエストボディの主要パラメータ、必要なツール指定 `web_search` `code_interpreter` 等）、認証方式（HTTPヘッダー名）、レスポンス形式（同期か非同期か、ポーリングが必要か、出力に含まれる引用・ソースの形式）を明らかにする。
3. 料金体系を明らかにする。モデル・機能ごとの入力トークン単価・出力トークン単価（キャッシュ有無別があれば併記）、Web検索呼び出し自体に別途課金があるかどうか、1回のDeep Researchリクエストで想定されるトークン消費量やコストの目安が公式情報として示されていればそれも記載する。
4. Deep Researchの実行にあたり事前準備が必要な事項（利用可能なOpenAI Organizationのティア制限、Rate Limit、実行時間の目安、非同期実行が必須かどうか、バックグラウンドモード `background: true` の要否等）を明らかにする。
5. 公式情報で確認できない項目があれば、その旨と、確認のために参照したURL・検索クエリの結果概要を明記する（存在しないという結論も、検索したが見つからなかったという事実として正直に報告すること）。

# 出力要件

- 日本語で記述すること。
- 公式ドキュメント・公式ブログ・公式Changelogを最優先で参照し、URLを明記すること。二次情報サイト（比較記事・価格まとめブログ等）を使う場合はその旨を明記し、公式情報と区別すること。
- 「提供されている」「提供されていない」を推測ではなく、実際に参照できたソースに基づいて明言すること。断定できない場合は「確認できなかった」と明記すること。
- サンプルのAPIリクエスト（curl等の疑似コード可）が公式ドキュメントに存在する場合は、そのまま引用すること。
- 参照した公式ドキュメント・情報源のURLをすべて出力の末尾に列挙すること。
- 選択肢の提示や好み・推奨の表明は不要。事実の確認結果のみを記述すること。

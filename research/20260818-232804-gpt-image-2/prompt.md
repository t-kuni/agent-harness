# このリポジトリについて

これは Claude Code（Anthropic製CLIエージェント）向けの「ハーネス」を管理するリポジトリである。ハーネスとは、AIエージェントが参照する知識ファイル群の総称で、`.claude/skills/<スキル名>/SKILL.md` の形式でスキルが定義される。このリポジトリには画像生成を行う `image-gen` スキルがあり、現在はOpenAIのCodex CLIをサブプロセス実行する方式で画像生成を行っているが、これをOpenAIの画像生成APIを直接HTTPリクエストで呼び出す方式に移行することを検討している。

その過程で、OpenAIが「gpt-image-2」という名称の画像生成モデルをリリースしているという情報がある。過去に行った別のリサーチでは、二次情報サイト（価格まとめブログ等）を中心に調査した結果、「gpt-image-1.5」が最新モデルであるという結論になったが、これは検索網羅性の不足により「gpt-image-2」の存在を見落としていた可能性がある。

# 問い

OpenAIは「gpt-image-2」という名称の画像生成モデルを2026年8月時点でリリース済みか。以下を明らかにせよ。

1. `gpt-image-2` というモデル名（または類似の名称）が、OpenAIの公式ドキュメント（platform.openai.com、developers.openai.com、openai.com/index 等）・公式ブログ・公式Changelogに存在するか。存在する場合はリリース発表日・正式なモデルID文字列を明記する。
2. 存在する場合、そのモデルのAPIエンドポイント（URL）、リクエストのJSON/multipartの形式、認証方式（HTTPヘッダー名）、レスポンス形式（Base64かURLか）、価格（1枚あたりまたは解像度・品質別の単価）を明らかにする。
3. `gpt-image-1` `gpt-image-1.5` `gpt-image-1-mini` など、2026年8月時点でOpenAIが提供している画像生成モデルのラインナップ全体を、公式ドキュメントに基づいて列挙する。
4. `gpt-image-2` に関する情報が公式ソースで確認できない場合は、その旨と、確認のために参照したURL・検索クエリの結果概要を明記する（存在しないという結論も、検索したが見つからなかったという事実として正直に報告すること）。

# 出力要件

- 日本語で記述すること。
- 公式ドキュメント・公式ブログ・公式Changelogを最優先で参照し、URLを明記すること。二次情報サイト（比較記事・価格まとめブログ等）を使う場合はその旨を明記し、公式情報と区別すること。
- 「存在する」「存在しない」を推測ではなく、実際に参照できたソースに基づいて明言すること。断定できない場合は「確認できなかった」と明記すること。
- 参照した公式ドキュメント・情報源のURLをすべて出力の末尾に列挙すること。
- 選択肢の提示や好み・推奨の表明は不要。事実の確認結果のみを記述すること。
